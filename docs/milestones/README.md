# Reading Shelf · the Codex build

Three prompts will develop the shared starter into a local reading library. Each chapter records a fresh proposal, its implementation report, and observed checks. The proposals use the installed Design Proposal skill and the user's standing authorization to implement.

Recorded checks describe the build session. Descriptions and navigation have been edited for publication. Use the milestone chapters to follow the build.
